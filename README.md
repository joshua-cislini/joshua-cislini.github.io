# [joshua-cislini.github.io](https://joshua-cislini.github.io/)
### [Is the webpage down?](https://joshua-cislini.cronitorstatus.com/)

Personal resume site of Joshua Cislini – Electrical Engineering student at HEIA-FR.
Plain HTML/CSS/JS, no build step, hosted on GitHub Pages. (`package.json` exists only for the CI tooling that
generates the social preview image; the site itself needs no build.)

## Features
- Light/dark theme: follows the OS setting until you pick one, then remembers your choice.
- Interactive particle background (DPR-aware, capped at 300 particles, static frame for "reduce motion").
- **Contact gate:** email, phone and the résumé PDF are only released after a Cloudflare Turnstile check, via a Cloudflare Worker.
- **GitHub contribution chart** rendered from a static JSON file refreshed daily by a GitHub Action (no third-party image service).
- **Auto-generated social preview:** `og-image.png` is rendered from an SVG template by a GitHub Action, using the
  name and titles found in `index.html`, so it never drifts out of sync with the page.
- Self-hosted fonts, strict Content-Security-Policy, Open Graph / Twitter cards and JSON-LD structured data.

## Structure
```
index.html                         page + CSS
js/theme-init.js                   sets theme before first paint
js/cronitor-init.js                Cronitor RUM config
js/main.js                         particles, theme, contact gate, badges, GitHub chart
fonts/                             self-hosted WOFF2 + OFL licenses
fonts/Inter.ttf, DMSerifDisplay.ttf  TTF copies for the OG image renderer (resvg can't read WOFF2)
data/github-contributions.json     generated by the workflow
scripts/generate-github-chart.mjs  contribution data generator
scripts/generate-og-image.mjs      reads index.html, fills the SVG template, renders og-image.png
scripts/og-image.svg               OG image template (1200×630): background, dot network, text placeholders
docs/SELF-HOSTING-FONTS.md         how the fonts are hosted / how to add more
og-image.png                       social preview (1200×630), GENERATED – don't edit by hand
package.json, package-lock.json    CI-only dependency (@resvg/resvg-js)
.github/workflows/                 chart refresh + sitemap lastmod & OG image
```

## Run locally
```bash
python3 -m http.server 8000   # then open http://localhost:8000
```
(Opening `index.html` via `file://` won't load the chart JSON; use a local server.)

To regenerate the social preview locally (optional, CI does this for you):
```bash
npm ci
node scripts/generate-og-image.mjs   # writes og-image.png
```

## Maintenance
- **Chart:** Actions → *Update GitHub contribution chart* → *Run workflow* (also runs daily).
  Requires Settings → Actions → General → *Workflow permissions* = **Read and write**.
- **Sitemap / `dateModified` / OG image:** the *Update Site Data (Sitemap & OG Image)* workflow runs when
  `index.html`, `js/`, `fonts/`, `scripts/` or `package*.json` change on `main` (or manually via *Run workflow*).
  It regenerates `og-image.png`, sets `lastmod` and `dateModified` to today, and commits the result.
- **Social preview text:** taken from `index.html`, nothing to edit in the image itself.
  - Name, job title and school come from the JSON-LD `Person` block.
  - To control the two subtitle lines explicitly, add these tags to `<head>` (they take priority over JSON-LD):
    ```html
    <meta name="og-image:line1" content="Electrical Engineering student · HEIA-FR">
    <meta name="og-image:line2" content="Electronics Technician">
    ```
  - The site URL comes from `og:url`. Long text is shrunk to fit and the translucent panels resize automatically.
  - To change the look (colours, dot network, layout), edit `scripts/og-image.svg`. Keep the `{{NAME}}`, `{{LINE1}}`,
    `{{LINE2}}` and `{{URL}}` placeholders; the script fails the build if any is left unfilled.
- **Social preview caching:** platforms cache previews (LinkedIn for days). After a change, refresh with
  LinkedIn's [Post Inspector](https://www.linkedin.com/post-inspector/) and Facebook's
  [Sharing Debugger](https://developers.facebook.com/tools/debug/); for Slack, Discord and X, share the link with a
  throwaway query string such as `?v=2`. Existing LinkedIn posts keep their old preview.
- **CSP:** defined in a `<meta http-equiv>` tag in `index.html` (GitHub Pages can't set headers). If you add a
  third-party script/API, open DevTools → Console, look for "Refused to…" errors and extend the matching directive.
