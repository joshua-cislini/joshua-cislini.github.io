# [joshua-cislini.github.io](https://joshua-cislini.github.io/)
### [Is the webpage down?](https://joshua-cislini.cronitorstatus.com/)

Personal résumé site of Joshua Cislini – Electrical Engineering student at HEIA-FR.
Plain HTML/CSS/JS, no build step, hosted on GitHub Pages.

## Features
- Light/dark theme: follows the OS setting until you pick one, then remembers your choice.
- Interactive particle background (DPR-aware, capped at 300 particles, static frame for "reduce motion").
- **Contact gate:** email, phone and the résumé PDF are only released after a Cloudflare Turnstile check, via a Cloudflare Worker.
- **GitHub contribution chart** rendered from a static JSON file refreshed daily by a GitHub Action (no third-party image service).
- Self-hosted fonts, strict Content-Security-Policy, Open Graph / Twitter cards and JSON-LD structured data.

## Structure
```
index.html                         page + CSS
js/theme-init.js                   sets theme before first paint
js/cronitor-init.js                Cronitor RUM config
js/main.js                         particles, theme, contact gate, badges, GitHub chart
fonts/                             self-hosted WOFF2 + OFL licenses
data/github-contributions.json     generated by the workflow
scripts/generate-github-chart.mjs  contribution data generator
docs/SELF-HOSTING-FONTS.md         how the fonts are hosted / how to add more
og-image.png                       social preview (1200×630)
.github/workflows/                 chart refresh + sitemap lastmod
```

## Run locally
```bash
python3 -m http.server 8000   # then open http://localhost:8000
```
(Opening `index.html` via `file://` won't load the chart JSON; use a local server.)

## Maintenance
- **Chart:** Actions → *Update GitHub contribution chart* → *Run workflow* (also runs daily).
  Requires Settings → Actions → General → *Workflow permissions* = **Read and write**.
- **Sitemap / `dateModified`:** updated automatically when `index.html`, `js/` or `fonts/` change on `main`.
- **CSP:** defined in a `<meta http-equiv>` tag in `index.html` (GitHub Pages can't set headers). If you add a
  third-party script/API, open DevTools → Console, look for "Refused to…" errors and extend the matching directive.
- **Social preview:** regenerate `og-image.png` when your title changes; check it with LinkedIn's Post Inspector.
